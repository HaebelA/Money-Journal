# Money Mindset Journal

Arianes persönliches Money Mindset Journal.

## Deploy auf Vercel (5 Minuten)

### Schritt 1 – GitHub
1. Gehe zu [github.com](https://github.com) und erstelle einen kostenlosen Account (falls noch keinen)
2. Klicke auf **"New repository"**
3. Name: `money-journal` → **Create repository**
4. Lade alle Dateien dieses Ordners hoch (Drag & Drop)

### Schritt 2 – Vercel
1. Gehe zu [vercel.com](https://vercel.com) → **Sign up with GitHub**
2. Klicke **"Add New Project"**
3. Wähle dein `money-journal` Repository
4. Alles so lassen wie es ist → **Deploy**
5. Nach ~1 Minute bekommst du deine URL z.B. `money-journal.vercel.app`

### Fertig!
Die URL kannst du mit jedem teilen – kein Account nötig zum Öffnen.
Daten werden lokal im Browser gespeichert (localStorage).
