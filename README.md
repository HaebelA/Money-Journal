# Money Mindset Journal

## Deploy auf Vercel

### Schritt 1 – GitHub
1. Gehe zu [github.com](https://github.com) → login
2. Öffne dein bestehendes Repository `HaebelA/Money-Journal`
3. Klicke **"Add file"** → **"Upload files"**
4. Entpacke das ZIP und lade **alle Dateien** hoch (`index.html` + `vercel.json`)
5. Klicke **"Commit changes"**

Vercel deployed automatisch – fertig!

## Lokal öffnen
Einfach `index.html` doppelklicken – funktioniert ohne Installation.
